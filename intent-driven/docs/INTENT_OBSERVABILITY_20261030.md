# 意图预检查、效果对比与执行稳定性

服务器：ubuntu@YOUR_SERVER_IP。前端继续通过 SSH 隧道访问 http://localhost:8099/。

## 页面行为

自然语言、MCS/PRB、UE、切片表单和账本回放统一先打开预检查。页面显示当前值、目标值、检查项、受影响的在线 UE、会话中断代价和执行计划。预检查失败时不能确认执行。

确认后执行保存的结构化意图，不再重新解析自然语言。预览凭据一次有效，180 秒后过期；CLI 在全局操作锁内重新检查当前参数、策略版本和影响对象，指纹变化或过期就停止。直接调用旧写接口的客户端仍会经过 CLI 的新预检查。

附加 UE 的 QoS 修改目前仅修改签约，不会自动重建该附加 UE 的现有会话；预检查会明确提示。新建切片继续要求核心网、RAN、UPF 加载及真实 UE 会话验收。

执行日志下和账本详情显示执行前后效果。每个受影响 UE 独立采集约 3 秒 TUN 接口字节差分、3 次 ICMP 的平均 RTT 和实际丢包。PRB 数据来自匹配的 E2 DU 回执，包括实际策略、峰值、限额命中、超限和同进程同版本的窗口增量。计数复位、接口变化、采样失败时保留“未获取”，不转换为零，也不据此宣称性能改善。

速率包含已有业务和探测流量，不是最大吞吐；不同窗口的差异不能证明因果改善。回滚后的页面将原始下发对比明确标为历史数据，当前策略用读取按钮确认。

## 读取与执行

- 同对象并发 GET 合并成一次 E2 查询，成功结果最多共享 2 秒，显示原采样时间和数据年龄。失败不缓存。
- 最多同时处理两个不同读取对象；超出时立即返回明确的忙状态，不加入长队列。控制前后使读取缓存失效；执行验证不走该缓存。
- E2 锁等待和 SDK 调用共享时间预算，避免每一层分别累计等待。前端读取 60 秒超时；后台页面停止定时读取，轮询从上次完成后计时，本页执行任务期间暂停常规轮询。
- 除 token/操作/PID/时间/权限可信的 DU 回执，还要求 SDK 输出实际的 E42 CONTROL ACK 接收记录。SDK 的同步返回值本身不能证明 ACK 已到达。
- 在全局锁保护下复用刚取得的执行前 DU 状态和写后验证结果，减少额外查询；写入后的独立 E2 回读仍保留。

诊断：`GET /api/ran/read-health`，包含实际查询数、共享数、失败数和最近错误。意图执行期间的 UI 读取会明确返回忙状态，避免争用控制通道。

## N6 出口

仅支持实验环境内已知 DN：192.168.73.135 / 192.168.73.136。恢复顺序为暂停 NWDAF SBI → 重启 SMF → 确认稳定进程、healthy 和本次启动后的 PFCP 关联 → 恢复 NWDAF → 恢复全部 UE。

验收读取 VPP 的 N6 默认路由，并抓取指定 UE/目的地址的 ICMP 探测包。DN2 内配置的 198.18.0.2/32 受控离链地址用于证明默认下一跳路径，无需公网目标。后台旧 DN 总收包计数不再作为失败条件。

切换失败会恢复旧 compose 值、重建原 UPF/SMF、恢复 UE，并将实际恢复结果保存到 `logs/egress-failure-*.json`；恢复失败会明确报告，不能显示成功。单元故障注入已验证运行态恢复路径。

SMF 镜像 v2.0.0 在 SIGTERM 退出清理时的 libnghttp2_asio 崩溃仍存在。2026-10-30 09:26:10 和 09:27:21 的测试停止阶段再次记录到该问题。此次没有升级/修补该镜像；新增恢复顺序和事务保护不能视作底层崩溃根治，也不能由一次切换成功推断长期稳定。

## 实测与复现

上线前同一组 10 个并发读取：3 个 HTTP 200、7 个 503，最长成功读取 64.877 秒。首轮上线后：10 个全成功，实际只启动 2 次 E2 查询，整组 43.326 秒。单次 E2 查询仍约 21 秒，未宣称达到低延迟控制。

真实操作均通过生产 UI HTTP 接口，保存账本并回滚：

- MCS 28 → 20：账本 `261030091932-c3da5a`，真实 MAC 最大观测值 20，三个 UE 的前后速率/RTT/丢包已采集，回滚到 28。
- 切片 3/000003 未限额 → 30%：账本 `261030092258-260f10`，BWP 106，峰值 31、峰值时限额 31、超限 0，随后回滚未限额。
- N6 DN1 → DN2：账本 `261030092539-e3b730`，VPP 路由、指定 UE 探测包和全部 UE 会话检查通过，随后回滚 DN1 并移除测试 DN2。

精简重复 E2 读取后再次实测：10 个混合并发读取全部成功，只发起 2 次 E2 查询，最长 43.322 秒；MCS 28 → 22（`261030093301-dc4c17`）执行阶段 63.049 秒，PRB 未限额 → 30%（`261030093522-e98a00`）执行阶段 117.081 秒，均完成独立回读验收及回滚。上述执行时间不包含页面预检查与后续回滚，不能作为时延保证。

新增观测、预检查、队列及恢复测试 17 项，既有 MCS/PRB 测试 19 项均通过。读取时间优先采用 DU 回执的真实采样时间，另保留接口获取完成时间，避免将 SDK 清理期间已经变旧的数据标为刚采样。

测试没有重启 CU、DU、FlexRIC；出口切换按预期重建了 UPF/SMF 和 UE 会话。初始检查发现重启后的 UE2/UE3 无会话，已恢复。服务器 curl 程序文件缺失，已重装同版本包，NRF 查询可读到四个切片。
